# Design System

## Direction

Monochrome operations console. The interface prioritizes scanability, ownership and next actions over decoration.

## Palette

- Canvas: off-white or near-black according to system preference.
- Primary text and actions: near-black in light mode, off-white in dark mode.
- Secondary surfaces and states: grey only.
- Semantic states use labels, weight, borders and patterns rather than hue.

## Typography

Use a neutral system sans-serif stack for the application interface. Preserve Times New Roman and KaiTi only inside email content editors where they represent outgoing email formatting.

## Shape and Depth

Use 8-12px radii, thin neutral borders and restrained shadows. Dense tables and operational lists should rely on grouping and spacing instead of excessive cards.

## Layout

Desktop uses a stable dark sidebar and a wide content workspace. Mobile uses a sticky top bar and a slide-in navigation panel. Administrators receive dedicated Team progress and All companies views.

## Motion

Use motion only for navigation and action feedback. Respect reduced-motion preferences.
